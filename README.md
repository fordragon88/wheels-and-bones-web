# Wheels & Bones — browser build

Educational wheelchair-repair game (English). Playable at https://fordragon88.github.io/wheels-and-bones-web/

This repository contains only the built web version (pygbag / WebAssembly). Keyboard controls: arrows, Tab, Enter; F1 — help.
Screen readers read the game through a live region on the page.
